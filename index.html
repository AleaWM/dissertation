Dissertation Replication Materials

Flood Risk Information, Floodplain Map Updates, and Property Values in Cook County, Illinois

Overview

This website provides supporting tables, figures, code notes, and documentation for my dissertation research on flood risk information and residential property values in Cook County, Illinois. It also includes supplementary and exploratory analyses beyond the dissertation.

The dissertation examines how housing markets respond to different forms of flood risk information, including FEMA Flood Insurance Rate Map updates and non-governmental flood risk information from First Street Foundation Flood Factor scores.

The materials hosted here are intended to make the dissertation analysis more transparent, reproducible, and easier to navigate.

This page provides a stable index to the additional materials referenced throughout the dissertation, Risk Perception and Real Estate Values in Cook County, Illinois. Items are listed in the order in which they appear in the dissertation so readers can locate the relevant supporting material using the printed page number.

The dissertation links to this landing page rather than directly to individual files. The links below can therefore be updated as the website changes without creating stale links in the dissertation itself.

The dissertation directs readers to the online repository for replication code, supplemental analyses, extended tables and figures, documentation, and additional methodological details.

This page should serve as the main guide to the repository and include:

  • a description of each major data source;
  • a diagram of the data-processing workflow;
  • an explanation of the repository’s folder structure;
  • links to the Question 1 and Question 2 materials;
  • instructions for reproducing tables and figures; and
  • a list of supplemental analyses not included in the dissertation document.

Research Questions

Research Question 1

How do residential property values respond when FEMA floodplain maps are updated and properties are added to or removed from the Special Flood Hazard Area?

This portion of the analysis focuses on FEMA Flood Insurance Rate Map updates, including preliminary and effective floodplain designations.

Research Question 2

How do residential property values respond to the public availability of First Street Foundation Flood Factor scores?

This portion of the analysis examines whether properties with higher Flood Factor scores sold for less after this information became publicly available, and whether those effects differed by existing FEMA floodplain status and region within Cook County.

Page 62: Question 1 additional robustness checks

Section 5.4.9 of the dissertation (printed pages 61-62) examines whether the Q1 FEMA map results depend on the choice of nearby comparison properties or on controls for local housing-market changes. The supporting page contains the existing model tables, with explanations of the samples and fixed effects used.

  • Properties within 300 meters of an SFHA: restrict the estimation sample to the existing GIS proximity list.
  • Spatial spillover exclusion: exclude nearby properties without a recorded SFHA transition, retaining properties that were ever added or removed.
  • Year-by-municipality controls: allow annual housing-market conditions to differ across municipalities within the nearby sample.
  • Year-by-township controls: show the nearby-sample models, followed by a comparison using the full prepared sample.
  • Year-by-FIRM-panel controls: allow annual conditions to differ across FIRM panels within the nearby sample.

Data Sources

data sources

The analysis combines several property, flood risk, and spatial data sources, including:

  • Cook County residential property sales data
  • Cook County parcel data
  • FEMA National Flood Hazard Layer data
  • FEMA Flood Insurance Rate Map panel information
  • Microsoft building footprint data
  • First Street Foundation Flood Factor data

Some source data may not be redistributed directly through this website because of file size. Where direct redistribution is not possible, this site documents the relevant data source, processing steps, and derived variables used in the analysis.

Spatial data and data cleaning/merging largely take place in the _targets.R file. Models and exploration are done in the .qmd files.
