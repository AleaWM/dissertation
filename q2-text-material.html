From coefficients to subgroup contrasts

For a linear log-price model, let x(post, h, s, r) be the model row for post-release status, high-score status, SFHA group, and region. The post-versus-pre contrast for a subgroup is [x(1,h,s,r) - x(0,h,s,r)]' beta. The high-versus-low difference in that post/pre contrast subtracts the same expression evaluated at h = 0 from the expression at h = 1. These are different estimands: a post/pre change for high-risk properties is not automatically the high-minus-low difference-in-differences effect.

For a contrast vector c, its standard error uses the full covariance matrix, sqrt(c' V c), including covariances among interaction coefficients. The existing analysis computes contrasts with marginaleffects::avg_comparisons(). Saved estimates are in log points unless explicitly transformed; 100 * (exp(estimate) - 1) gives the corresponding percentage conversion, not estimate itself. Nonlinear transformation and averaging should not be interchanged without specifying the target estimand.

The existing marginal-effect sections display the saved contrasts. Their nearby code records each call’s variables, by, and any newdata grid. These details determine the comparison and weighting and should be retained when linking a dissertation table to its underlying model.

What the anticipation checks can establish

The pre-event slope tests and the pre-2020 placebo sample address patterns before the recorded Flood Factor release. The existing placebo code defines its post period as years greater than 2017, so 2018-2019 are post-placebo and 2017 itself remains pre-placebo. A significant placebo interaction may reflect differential trends, other events, or anticipation; it does not distinguish among them. A non-significant result cannot rule out advance information or limited power. The assumed information date and sample construction must be considered alongside these diagnostics.

## From coefficients to subgroup contrasts {#q2-coefficient-contrasts}

For a linear log-price model, let `x(post, h, s, r)` be the model row for post-release status, high-score status, SFHA group, and region. The post-versus-pre contrast for a subgroup is `[x(1,h,s,r) - x(0,h,s,r)]' beta`. The high-versus-low difference in that post/pre contrast subtracts the same expression evaluated at `h = 0` from the expression at `h = 1`. These are different estimands: a post/pre change for high-risk properties is not automatically the high-minus-low difference-in-differences effect.

For a contrast vector `c`, its standard error uses the full covariance matrix, `sqrt(c' V c)`, including covariances among interaction coefficients. The existing analysis computes contrasts with `marginaleffects::avg_comparisons()`. Saved estimates are in log points unless explicitly transformed; `100 * (exp(estimate) - 1)` gives the corresponding percentage conversion, not `estimate` itself. Nonlinear transformation and averaging should not be interchanged without specifying the target estimand.

The [existing marginal-effect sections](#main-marginal-effects) display the saved contrasts. Their nearby code records each call's `variables`, `by`, and any `newdata` grid. These details determine the comparison and weighting and should be retained when linking a dissertation table to its underlying model.

### What the anticipation checks can establish {#q2-anticipation}

The pre-event slope tests and the pre-2020 placebo sample address patterns before the recorded Flood Factor release. The existing placebo code defines its post period as years greater than 2017, so 2018-2019 are post-placebo and 2017 itself remains pre-placebo. A significant placebo interaction may reflect differential trends, other events, or anticipation; it does not distinguish among them. A non-significant result cannot rule out advance information or limited power. The assumed information date and sample construction must be considered alongside these diagnostics.
